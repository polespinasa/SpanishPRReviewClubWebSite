Pregunta 4 -> La regla de selección canónica para transacciones no confirmadas tiene en cuenta el menor peso. “Peso” incluye los datos de witness. ¿Porque no usamos el mayor feerate en lugar del peso? ¿Podría la variante de mayor peso tener un feerate mayor que una variante menos pesada?

Santochibtc 30/07/2026 19:33
Para calcular el freerate necesitas saber el valor de los inputs y pueden no estar disponibles, en cambio el peso sí se puede calcular. La variante de mayor peso no puede tener un feerate mayor, porque al fee es el valor de las entradas menos el de las las salidas, independientemente del witness.
